## The two faults worth reading, because both were invisible to everything

Same lesson as 2026-09-03, from a different direction: **the build, the unit suite, `tsc`,
ESLint and Lighthouse were green through both of these.**

### 1. An open nav panel buried the hero copy

Below `md` the dropdown panel shipped as an in-flow `w-full` flex item, because the plan
specified "a sheet that pushes the rest of the bar down". The hero reserves a **fixed**
amount of top space for the overlaid header, so anything that makes the header taller puts
the first line of copy behind it. Opening a panel took the header from 88.5px to **186px**
and `/about`'s clearance to **−58px**, on four of seven section pages.

It survived a per-task review because the panel's E2E tap test ran on `/` — the one route
with 332px of hero slack — and asserted no geometry at all. The final whole-branch review
found it by measuring the *opened* state.

Fixed by anchoring the panel out of flow below `md`, which is what the same branch had
already done for the Investor Login disclosure. **The rule is now written down in
`src/lib/headerReservation.ts`: the header's height must not depend on an interaction.**

### 2. CI renders with fallback fonts, and the header grows 40px

`npm run test:e2e` passed locally and failed in CI on four tests. Not the known
`ECONNRESET` flake — the wider fallback face makes the header's **row one wrap**, taking it
from 113px to **153px** at 320px against a fixed 128px reservation, so clearance went to
**−25px** on `/about` and `/insights`.

Reproduce it in one line: `page.route('**/*.{woff,woff2,ttf,otf}', r => r.abort())`.

This is a real defect and not a CI artifact — a phone on a slow connection paints fallback
fonts first, so a real visitor sees copy under the header during that flash. The
reservation is now `pt-48 min-[390px]:pt-36 md:pt-28`, **sized against the fallback face**
rather than against the webfont-loaded numbers, and three E2E tests block the font requests
so the case cannot hide again. Worst clearance with fonts blocked is now **+39px**.

## The rules that matter most

**1. A new required `siteSettings` leaf needs THREE edits**, not two: the schema,
`REQUIRED_SITE_SETTINGS`, and `SITE_SETTINGS_QUERY`. Miss the query and `next build` fails
on all 29 pages while **the release gate stays green**, because the gate builds its own
projection from the array's `groq` and never consults the query the layout runs.
`tests/unit/requiredContent.test.ts` catches it. That 29-page failure was reproduced
deliberately this session to prove the guard fires.

**2. `content-integrity.test.ts` needed no edit to gate nine new leaves.** That is PR 2a
paying for itself, and this was the first change to test the claim. The next required field
really is free.

**3. An OPTIONAL leaf still needs projecting, and nothing will tell you.**
`siteSettings.dealStoryHeading` is deliberately optional, so it is not in
`REQUIRED_SITE_SETTINGS` — which means neither the layout's throw nor the release gate
would notice it missing from `SITE_SETTINGS_QUERY`. It would read `undefined` on every
property page regardless of what the Studio holds. One assertion in
`tests/unit/queries.test.ts` is the whole of its protection.

**4. Applying a migration ahead of its code is safe for an ADDITION.** Exercised correctly
again: nine nav labels, `dealStoryHeading` and the `strategyPage` document were all applied
to production **before** the code that requires them, and the live site was then confirmed
unchanged — which is the addition half of the rule working. `--only=nav-labels` is the new
step. Full account in `docs/deploys-and-migrations.md`.

**5. The `trackRecordPage` document is still in the dataset, unread.** That is deliberate
and it is the rollback path: restoring `/track-record` is a `git revert`, not a rewrite.
Do not delete it without deciding you no longer want that.

## Traps found this session

All added to the README.

- **CI renders with fallback fonts.** See fault 2 above. A layout whose height depends on
  text metrics needs its margin sized against the fallback face, and the guard has to block
  the font requests or it cannot see the case.
- **A fixed padding cannot reserve space for a variable-height header.** The header's
  height moves with font loading, with how four CMS-authored nav labels wrap, and with the
  CMS-authored CTA label's length. Anything that grows it on interaction is a defect.
- **An E2E test that performs a gesture and asserts nothing looks like coverage.** The
  panel tap test did exactly that, on the one route with enough slack to hide the bug.
- **`{/* … */}` between JSX attributes is a parse error** (TS1005). Brace comments are only
  valid in children position; use `//` on its own line.
- **`as const` on a tuple makes `.flatMap((x) => x.optionalKey)` fail under strict TS.**
  Two of `NAV_TREE`'s four elements have no `children` key, so the inferred union errors.
  Annotate the callback parameter with the interface.
- **`toContain('pt-32')` matches a `min-[390px]:pt-32` variant.** A test meaning to pin a
  base Tailwind token must assert the first, unprefixed token.
- **For a real mouse click, `pointerenter` fires before `click`.** A hover-to-open panel
  that also toggles on click closes immediately, so a mouse user can never open it. Scope
  suppression to `event.detail > 0` — a keyboard-synthesised click on a button carries
  `detail === 0`.
- **`npm start` DOES work here** despite an advisory warning about `output: 'standalone'`.
  A report this session claimed otherwise; it was wrong, and the claim would have sent the
  next reader down a wrong path.

## How Hunter wants the work done

Superpowers workflow: a plan first, then TDD, then a code review before anything merges.
Open a PR, poll CI until no row reads `pending` (`gh pr checks --watch` exits before the
`build` job registers), merge, then trigger the Railway deploy — auto-deploy is off, so
merging ships nothing. Redeploy the hosted Studio after every schema change, **from merged
code**.

**Run things and read the output.** Both of this session's faults passed every automated
gate. One was found by measuring the rendered page in a state nobody had thought to
measure; the other by CI rendering in a font nobody had thought about. Measure the real
page, in the states a user can actually produce, and open the Studio.
